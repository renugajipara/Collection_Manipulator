🎓 Student Data Organizer

A Menu-Driven Collection Manipulator in Python

📌 Project Overview

The Student Data Organizer is a menu-driven Python application that manages student records using core Python collection data types:

✅ List

✅ Tuple

✅ Set

✅ Dictionary

This project demonstrates intermediate-level Python concepts including:

String manipulation

Type casting

Mutability vs Immutability

del keyword

Match-case (Python 3.10+)

Data organization using nested collections

🚀 Features

✔ Add multiple students
✔ Display all student records
✔ Update student details (Age, Grade, Subjects)
✔ Delete student using ID
✔ Display unique subjects offered
✔ Uses tuple for immutable student ID & DOB
✔ Uses set to ensure no duplicate subjects
✔ Menu-driven interactive system

🧠 Concepts Used

| Concept       | Implementation                     |
| ------------- | ---------------------------------- |
| List          | Stores all student records         |
| Tuple         | Stores immutable (Student ID, DOB) |
| Set           | Stores unique subjects             |
| Dictionary    | Stores student data                |
| Type Casting  | Converts input to `int`            |
| `del` Keyword | Deletes student record             |
| Match-Case    | Menu handling                      |

🗂 Data Structure Used

Each student is stored as a dictionary inside a list:

{
  "id_info": (student_id, dob),
  "name": name,
  "age": age,
  "grade": grade,
  "subjects": {"Math", "Science"}
}
